# Java Project Name

## Описание
Приложение для учёта и управления сетевыми объектами (сетями, устройствами
и их взаимосвязями). Приложение позволит регистрировать сети, добавлять к ним
устройства (например, роутеры, свитчи, серверы) и задавать связи между устройствами
(например, подключение по кабелю или по Wi-Fi).

## Технологии
* Java 21
* Maven
* JDBC
* JUnit5

## Запуск
```bash
mvn clean install
java -jar target/my-app.jar
